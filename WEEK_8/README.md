E-commerce Data Analysis Project
Overview
This project shows how to clean data using Python and analyze it using SQL.

Steps
Clean raw CSV files using Python (Pandas)
Fix missing values and invalid data
Load cleaned data into MySQL
Run SQL queries for analysis
Data Used
customers.csv
products.csv
orders.csv
order_items.csv
Key Analysis
Top customers by spending
Monthly sales trend
Top selling products
Return rate of products
Tech Stack
Python (Pandas)
MySQL
SQL
How to Run
Run data_cleaning.py
Create tables using schema.sql
Import CSV files into MySQL
Run analysis.sql
Folder Structure
data → CSV files
