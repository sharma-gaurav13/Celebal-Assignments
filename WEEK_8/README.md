# E-commerce Data Analysis Project

## Overview
This project shows how to clean data using Python and analyze it using SQL.

## Steps
1. Clean raw CSV files using Python (Pandas)
2. Fix missing values and invalid data
3. Load cleaned data into MySQL
4. Run SQL queries for analysis

## Data Used
- customers.csv
- products.csv
- orders.csv
- order_items.csv

## Key Analysis
- Top customers by spending
- Monthly sales trend
- Top selling products
- Return rate of products

## Tech Stack
- Python (Pandas)
- MySQL
- SQL

## How to Run
1. Run `data_cleaning.py`
2. Create tables using `schema.sql`
3. Import CSV files into MySQL
4. Run `analysis.sql`

## Folder Structure
- data → CSV files  
- scripts → Python code  
- sql → SQL queries
