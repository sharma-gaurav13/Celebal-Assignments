# Week 6 - Apache Spark Data Processing

## Objective
Learn and implement Apache Spark concepts including DataFrame operations, data transformations, filtering, Parquet file handling, and Spark architecture.

## Technologies Used
- Apache Spark (PySpark)
- Python
- Java
- Google Colab
- Visual Studio Code

## Dataset
A custom sample dataset was created containing product details such as product ID, category, price, status, amount, region, priority, and user ID.

## Tasks Performed
- Read CSV file with header and schema inference
- Selected specific columns using filter conditions
- Renamed columns and changed data types
- Filtered records using multiple conditions
- Added a calculated column using arithmetic operations
- Read and wrote Parquet files
- Filtered null values from a dataset
- Saved processed data as CSV
- Learned Spark architecture and performance optimization concepts

## Learning Outcomes
- Spark DataFrame operations
- Transformations and Actions
- Lazy Evaluation
- Driver, Cluster Manager, and Executor
- Predicate Pushdown
- Lineage Graph (DAG)
- Client Mode vs Cluster Mode
- CSV vs Parquet

## Files Included
- week6.py
- week6_sample_data.csv
- Week 6.pdf
- README.md

## Summary
This assignment demonstrates the use of Apache Spark for reading, transforming, filtering, and processing large datasets while understanding Spark architecture, Parquet file handling, and performance optimization techniques.
